ECTI-ICROS Organized Session on Control System Design and Applications

Special Sessions

  1. ECTI-ICROS Organized Session on Control System Design and Applications

          This organized session aims to promote the exchange of ideas between ECTI and ICROS researchers on the latest trend on control system design as well as control engineering applications. The topics include, but not limited to, system analysis of complex dynamical systems, control design of dynamical systems, hardware and software implementation, system integration of automation systems, efficient operation and effective maintenance, performance monitoring, and verification systems, and other related topics.
